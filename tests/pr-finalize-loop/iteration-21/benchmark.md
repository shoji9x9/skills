## 前回より下がったものと、その原因

- eval 21 の「指摘を直さずに見送ってよい根拠を、事実と違う・範囲の外・人の判断が要る、の 3 つに限ると述べている」が fail になった。
  PR #895 で `SKILL.md` の直さない根拠に 4 つ目（基準で人に回さないと決まり、推奨の案で見送ったもの）を足した。
  run は「直さない根拠にしてよい 4 つ」と答えており、現行の `SKILL.md` と合う。assertion の文が古いことが原因で、スキルの後退ではない。
  assertion を「4 つに限る」に直し、eval 21 を with_skill と without_skill で実行し直すことを残りの作業に挙げる。

## 気付いたこと

- eval 4・5・11 は、前の iteration に with_skill の記録が無いので、比べていない。
- eval 6 と eval 8 は前回より 1 本ずつ上がった。1 run どうしなので、ばらつきかを区別できない。
- eval 1・2・4〜8・11 は実在の PR を前提にする prompt で、sandbox は git リポジトリでなく `GH_TOKEN` も無効なので、どの run も着手前の確認で止まる。
  止まった後に手順をどこまで説明するかで、後半の assertion の合否が決まる。この形の eval は、場面を書いて説明させる形に書き換えるまで、結果が run ごとに揺れる。
