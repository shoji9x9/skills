# 表示の文に同じ書き出しの分岐を足したら、既存の assertion をその分岐の理由まで絞る

## 事象

PR #665 の 2 回目のレビューの指摘で、`status` の「このブランチの判断」に `対象外（.agent-usage/ が無いので…）` の分岐を足した。
既にある分岐の `対象外（デフォルトブランチでは…）` と、書き出しが同じである。
デフォルトブランチの表示を確かめる assertion は `/このブランチの判断: 対象外/` だったので、デフォルトブランチの判定を外す変異でも、新しい分岐の文に当たって通った。
変異 2 件が FAIL になり、assertion を絞ってから、全件（71 件）をもう一度実行した。

## 根本原因

- なぜ変異が生き残ったか → assertion が、2 つの分岐に共通する書き出しだけを照合していた
  - なぜ共通の書き出しだけだったか → assertion を書いたときは、`対象外` の分岐が 1 つしか無かった
    - なぜ分岐を足したときに直さなかったか → 分岐を足すときに、同じ書き出しを照合する既存の assertion を探す手順が無かった ← 根本原因
- `.agents/rules/state-space-and-mutation-proof.md` §1「一致の単位」の、一方が他方の一部になる入力の項と同じ形である。照合する側（assertion）に当てていなかった

## 提案

利用者に表示する文に分岐を足すときは、その文と同じ書き出しを照合する既存の assertion を grep で挙げ、それぞれを分岐の理由の部分まで絞ってから、ミューテーションテストを実行する。

- 適用先の候補: `.agents/rules/state-space-and-mutation-proof.md` §1「一致の単位」に、照合する側（テストの assertion）にも当てると 1 行足す
