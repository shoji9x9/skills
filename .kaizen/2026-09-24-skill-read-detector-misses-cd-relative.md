# スキルを読んだかの判定が cd 後の相対パスを数えず、読んだ run を集計から落とす

## 事象

parity-suite の eval 44 で with_skill の 2 run がどちらも `invalid_run: true` になり、
`build-skill-eval-benchmark.js` が「採点済みの run が無い」で exit 2 になった。
raw では `cd <スキル配下>` の後に相対パスで SKILL.md を読んでおり、回答も行番号を引いていた。
手順書どおり取り直したが、同じ読み方で再び除外された。

## 根本原因

- なぜ除外? 判定器が相対パスをスキルのパスと照合できない（cwd を追っていない）
- なぜ追っていない? 複合コマンドを証拠にしない規則を入れたとき、「取りこぼしは追加 run で吸収できる」前提を置いた
- なぜ前提が崩れた? 読み方は偶然ではなくモデルの習慣（cd してから読む）で、取り直しても同じ形になる。前提を実測で確かめていなかった

## 提案

cd 後の相対パスでの読み取りを、閉じた条件で読み取りに数えるよう判定器を直す（Issue #455 で追跡）。

- 取りこぼしを「追加 run で吸収できる」と扱う規則は、同じ run が 2 回続けて落ちたら読み方を raw で確かめ、判定器側の Issue にする
