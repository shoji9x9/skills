# 前の反復で書いた外向きのスクリプトを中身の確認のつもりで実行し、PR に同じコメントを重ねて投稿した

## 事象

PR #908 の pr-finalize-loop の 5 回目の反復で、返信の本文を新しいファイル（`r908top3.md`）に書いた。
その後、前の反復で書いた `reply908c.sh` を、本文のパスを確かめるつもりで `bash` で実行した。
このスクリプトは前の本文（`r908top2.md`）を投稿して再レビューを依頼する作りだったので、前の回と同じコメントが PR に重なって投稿された。
自分の投稿だったので削除し、正しい本文を投稿し直した。

## 根本原因

- 重ねて投稿したのは、外向きの操作をするスクリプトを、読むためのコマンド（`cat`）ではなく `bash` で起動したからである
- 起動したのは、スクリプトが本文のパスを固定で持ち、反復ごとに作り直す取り決めが無いまま、前の回のものを使い回そうとしたからである
- 使い回したのは、PR に投稿するスクリプトを、本文のパスを引数で受ける形で書かず、反復ごとにファイル名を変えて残していたからである

## 根拠

1 回の観測だが、実行した呼び出しと投稿されたコメントの本文が一致したので medium とする。
観測: 投稿されたコメント（6650877443）の本文が `r908top2.md` の先頭と一致した。
KEDB 照合: 「重ねて投稿」で `2026-11-03-review-agent-reposts-stale-comments.md` が当たった。前の回の成果物を投稿の対象に含めた点は同じだが、あちらはレビューのエージェントが投稿の対象を選んだ誤りで、原因が違う。

## 提案

外向きの操作（投稿・依頼・merge）をするスクリプトは、本文のパスや番号を引数で受け取る形で書き、中身を確かめるときは `bash` で起動せずに `cat` で読む。

- 反映先の候補: `AGENTS.md`「外向きの操作と破壊的な操作」と `docs/agent-workflow.md` の同じ節
