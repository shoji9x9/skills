## 特性化できなかった箇所と理由

<!-- 種別: データ不足（→ golden-dataset へ戻す）/ 認証範囲不明 / スコープ外の副作用（メール・外部連携）/ ローディング indicator 無し / 採取環境依存 / 出力に到達不可 / ストレージ投入スコープ外 等 -->
<!-- 種別の判定（対象・対象外・条件付き）は replace-strategy の references/scope.md を正本として引く。 -->

| 箇所 | 種別 | 理由 | 対応（golden-dataset へ戻す／スコープ外として記録／要ユーザー確認） |
|---|---|---|---|
| 本文の字幅（例） | 採取環境依存 | フォントスタックに総称ファミリーを含み、採取環境と利用者環境で CJK のフォールバック先が変わる | 未検証として残す（採取環境でだけ一致するため差分器では捉えられない） |
| 一覧の空状態（例） | データ不足 | このパターンのシードが無く空リストしか確認できない | golden-dataset へ戻してバージョンを上げ、影響ベースラインを再取得 |
| 確認メール送信（例） | スコープ外の副作用 | メール・外部連携はスコープ外 | 記録のみ（検証しない） |
| 一覧のローディング表示（例） | 明示的な loading UI 無し | indicator が無い画面は対象外 | 記録のみ |
| 管理者専用画面（例） | 認証範囲不明 | 認証が必要な範囲を特定できない | 未検証として残す（確認済みにしない） |
| 夜間バッチの出力 CSV（例） | 出力に到達不可 | 出力先がコンテナ内で、テスト環境のファイルシステムに到達できない | 未検証として残す（到達手段が用意できれば対象に戻す） |
| 添付ファイルの保存結果（例） | ストレージ投入スコープ外 | ストレージ実体へのゴールデンデータ投入は v1 スコープ外で、事前配置に依存する状態を作れない | 記録のみ（検証しない） |
