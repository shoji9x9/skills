## 特性化できなかった箇所と理由

<!-- 種別: データ不足（→ golden-dataset に戻す）/ 認証範囲不明 / スコープ外の副作用（メール・外部との連携）/ 採取環境依存 / 採取値の射程外 / 撮影状態の対象外 / 撮影範囲の対象外 / 性能の対象外 / 出力に到達不可 / ストレージ投入スコープ外 /
     判断待ち（--autonomous の保留。pending-decisions.json の pending_decisions の id を理由に書く）など -->
<!-- 種別の判定（対象・対象外・条件付き）は、replace-strategy の references/scope.md を原本として読む。 -->

| 箇所 | 種別 | 理由 | 対応（golden-dataset へ戻す／スコープ外として記録／要ユーザー確認） |
|---|---|---|---|
| カスタムカーソルの画像（例） | 採取値の射程外 | `cursor` の `url()` は、同一オリジンを畳んだパスで比べる。現側と新側が同じパスで別のバイトの画像を配信していると、形の差が特性照合にも画素にも現れない | 未検証として残す（確認済みにしない） |
| 本文の字幅（例） | 採取環境依存 | フォントスタックに総称ファミリーを含み、採取環境と利用者環境で CJK のフォールバック先が変わる | 未検証として残す（採取環境でだけ一致するので、差分ツールでは検出できない） |
| 一覧の空状態（例） | データ不足 | このパターンのシードが無く、空のリストしか確かめられない | golden-dataset に戻してバージョンを上げ、影響するベースラインを再取得する |
| 確認メールの送信（例） | スコープ外の副作用 | メールと外部との連携はスコープ外 | 記録だけ（検証しない） |
| 管理者だけが使う画面（例） | 認証範囲不明 | 認証が必要な範囲を特定できない | 未検証として残す（確認済みにしない） |
| 列を選ぶ吹き出し（例） | 撮影状態の対象外 | `popup_inventory` で数えたが撮らない（同じ吹き出しを一覧の機能のスイートで撮る）。撮らないコンテナの中身の見た目は、3 つの比較方法のどれにも出ない | 未検証として残す（`popup_inventory[].reason` と同じ文言） |
| メニューの項目の不活性の表示（例） | 撮影状態の対象外 | 網羅表から `disabled` が導かれたが、現行ではすべてのロールで項目が活性になり、不活性の条件を作れない | 未検証として残す（`visual_state_coverage.rows[].reason` と同じ文言） |
| 条件の行を足した後のグリッドの高さ（例） | 採取値の射程外 | 反応の網羅表の `layout` は、撮影したビューポートでだけ測る。操作の後の組み方が窓の寸法にどう追従するかは、寸法の式（初期表示だけ）にも入らない | 未検証として残す（確認済みにしない） |
| 一覧の 2 画面目以降（例） | 撮影範囲の対象外 | 仮想スクロールで全画面の撮影ができず、コンテナの中身が見えている部分より大きいまま撮っている | 未検証として残す（`capture_scope_exemptions[].reason` と同じ文言） |
| 絞り込みを押した後の再描画の速さ（例） | 性能の対象外 | 性能は初期表示の読み込みだけを採る（`performance`）。操作の後の速さとレイアウトの揺れは、どの比較方法にも出ない。`performance.declared: false` にしたときも、同じ種別で `performance.reason` と同じ文言を書く | 未検証として残す（確認済みにしない） |
| 夜間バッチの出力の CSV（例） | 出力に到達不可 | 出力先が Docker のコンテナの中にあり、テスト環境のファイルシステムから届かない | 未検証として残す（届く手段を用意できれば対象に戻す） |
| 添付ファイルの保存の結果（例） | ストレージ投入スコープ外 | ストレージの実体へのゴールデンデータの投入はスコープ外で、事前の配置に依存する状態を作れない | 記録だけ（検証しない） |
