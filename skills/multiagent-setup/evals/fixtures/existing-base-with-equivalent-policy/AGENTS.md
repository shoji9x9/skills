# 在庫管理プロジェクト

## プロジェクト概要

店舗スタッフが日々の在庫数を記録し、月次棚卸しで差異を確認するためのアプリケーション。

## ワークフロー

- 月次棚卸しの集計仕様を変更するときは、店舗運用担当者のレビューを受ける。
- 変更後は `pnpm test` で検証する。

## 回答方針

- 読み手に馴染みがない可能性のある用語は、必要な場合だけ使い、初出時に平易な言葉で短く説明する。
- 安全かつ妥当な前提で進められる場合は、不要な判断を利用者へ委ねない。
- 利用者の判断が必要な場合は、推奨案を先に示し、理由、主な影響、代替案を添える。
- 安全性、仕様、権限に関わる必要な確認は省略しない。
- 用語を完全に禁止したり、すべての説明を長くしたりしない。
