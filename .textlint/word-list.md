# 使わない語

<!-- .textlint/words.json から scripts/gates/check-word-list.js --fix で生成する。手で直さない。 -->

人が読む文章と人への応答では、次の語を使わず言い換えて書く。

<!-- textlint-disable -->

| 使わない語 | 言い換え |
| --- | --- |
| 正本 | 原本、〜で定義する |
| 正典 | 原本 |
| 黙って | 警告なしに、エラーにならずに |
| 無言で | 警告なしに |
| 静かに（比喩） | エラーにならずに、警告なしに |
| 壊れる | 不正な、失敗する、など起きることを書く |
| 経路 | 方法、処理の流れ、呼び出し方 |
| ゲート | チェック、必須チェック、制限 |
| 門（比喩） | チェック |
| 効く | 有効になる、機能する、反映される |
| 走る | 実行する、実行される |
| 穴 | 抜け、検出できない範囲 |
| 落とし穴 | 注意点 |
| 漏れ | 忘れ、抜け、外れる |
| 入口 | 起点、呼び出し元 |
| 混ざる | 含まれる、混在する |
| 〜から引く（読む意味） | 〜から取得する、〜から読む |
| 既定では | デフォルトでは |
| 土台 | 基になる、方針 |
| 崩す | 成り立たなくなる、変えない |
| 破綻 | 誤り、不具合 |
| 〜に落ちる（比喩） | 〜として扱われる、〜になる |
| 道具 | ツール |
| 帰結 | 結果、そのため |
| 焼く・焼き込む | 固定する、埋め込む |
| 見張る | 監視する、チェックする |
| 値を動かす | 値を変える |
| 死活 | 稼働状況 |
| 原初 | 最初、元の |
| 無差別 | すべて、区別なく |
| 太る | 大きくなる、増える |
| 原料 | 入力、元のデータ |
| 核心 | 要点 |
| 構図 | 関係、構成 |
| 溶かす | なくす、まとめる |
| 定番 | よく使われる、標準的な |
| 定石 | よく使われる方法 |
| 〜器（差分器・実行器など） | 差分ツール、ランナー、スキャナ、ジェネレータ |
| 被覆 | 網羅、対応 |
| 契約 | 仕様、取り決め、共通の設定 |
| 〜に倒す | 〜として扱う、〜と判定する |
| 〜へ倒れる | 〜と判定されてしまう |
| 写す | コピーする、反映する、転記する |
| 写る | 記録される、表示される |
| 写し | コピー |
| 配線（比喩） | 組み込み、接続、設定 |
| 弁別 | 区別 |
| 写像 | 変換、対応づけ |
| 化ける | 誤って〜と判定される |
| 取り直す | 再取得する、もう一度測る |
| 来歴 | 出所、入手経緯 |
| fail-closed・fail-open・fail-safe | 振る舞いを書く（判定できないときは失敗として扱う、など） |
| 陽性コントロール・陰性コントロール | 検出されることの確認、誤検知しないことの確認 |
| 探針 | 計測スクリプト、プローブ |
| 縮退 | 機能を減らして動く |
| 変異実証 | ミューテーションテスト |
| 変異宣言 | ミューテーションテストの定義ファイル |
