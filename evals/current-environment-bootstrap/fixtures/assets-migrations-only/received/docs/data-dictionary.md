# データ辞書（受領物・2026-08-12）

## ORDERS.STATUS（受注ステータス）

| 値 | 名称 | 説明 |
|---|---|---|
| 0 | 未処理 | 受注登録直後の状態 |
| 1 | 出荷準備中 | 引当が完了した状態 |
| 2 | 出荷済 | 出荷実績が登録された状態 |
| 9 | 取消 | 受注が取り消された状態 |

正常系の遷移は 0 → 1 → 2。0 および 1 からは 9 へ遷移できる。

## APP_USERS.ROLE_CODE

| 値 | 説明 |
|---|---|
| ADMIN | 全機能 |
| OPERATOR | 受注一覧の参照と出荷登録のみ |

## 初期ユーザー

構築時に `admin` / `operator` の 2 ユーザーを作成する。パスワードは構築担当が設定する。

## 受注一覧の既定の並び順

得意先名の昇順。同名の場合は受注番号の昇順。
