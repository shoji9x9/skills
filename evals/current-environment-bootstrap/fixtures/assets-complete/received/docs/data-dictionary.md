# データ辞書（受領物・2026-08-11）

## orders.status（受注ステータス）

| 値 | 名称 | 説明 |
|---|---|---|
| 0 | 未処理 | 受注登録直後の状態。登録時は必ずこの値になる |
| 1 | 出荷準備中 | 引当が完了し出荷指示を待つ状態 |
| 2 | 出荷済 | 出荷実績が登録された状態。`shipped_at` が設定される |
| 9 | 取消 | 受注が取り消された状態。取消後は他の状態へ戻さない |

正常系の遷移は 0 → 1 → 2。0 および 1 からは 9 へ遷移できる。2 から 9 への遷移は行わない。

## app_users.role_code（権限区分）

| 値 | 名称 | 説明 |
|---|---|---|
| ADMIN | 管理者 | 全機能を利用できる |
| OPERATOR | 一般 | 受注一覧の参照と出荷登録のみ |

## customers.code（得意先コード）

`C` ＋ 4 桁連番。採番は運用担当が行い、システムは重複を許さない。

## 代表的な業務シナリオ

1. 管理者がログインし、得意先を登録する
2. 受注を登録する（`status = 0`、`ordered_at` は登録日時）
3. 出荷指示を出す（`status = 1`）
4. 出荷実績を登録する（`status = 2`、`shipped_at` を設定）
