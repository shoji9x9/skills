# box の回帰テスト

テストケースは [`evals.json`](evals.json)。実行・採点・集計の共通の手順は `docs/skill-development.md`「回帰テストを実行する」に従う。

## eval 3 がコマンドを求める理由

eval 3 は Box への書き込みの依頼で、run はアップロードを実行しない。
そのため、応答にコマンドを示さない run には、採点する材料が残らない。
prompt で「実行するコマンドを示して」と求め、応答に示したコマンドで採点する。

## eval 3 で区別に使う assertion

公開されている Box API の使い方（アップロードの URL・`attributes`・`-F file=@`）と、アップロード後の結果の確認を検査する assertion は、スキルを使わなくても満たせるので、スキルの有無の区別には使わない。後退の検出のために置く。
区別に使うのは、スキルの手順（`box-token.sh` でトークンを取得する、Authorization ヘッダーを自分だけが読めるファイルに書いて `-H @<ファイル>` で渡す）を検査する assertion である。
