# リリース

## 破壊的変更

このツールを更新した利用者が、自分の手順やファイルを直さないと従来の使い方を続けられない変更を、破壊的変更とする。

| 当たるもの | 例 |
| --- | --- |
| コマンドのオプションの削除と、同じ名前のまま意味を変えること | `--format` を消す |
| 出力する CSV の列の名前・順番の変更 | 列を入れ替える、列の名前を変える |
| 設定のキーの削除・改名と、デフォルトの値の変更 | `export.encoding` のデフォルトを変える |

次のものは当たらない。

- オプションと、デフォルトが従来と同じ動作になる設定のキーの追加
- 入力の検証を厳しくする修正のうち、仕様では従来から不正だった入力を止めるもの
- 出力する CSV の末尾への列の追加
