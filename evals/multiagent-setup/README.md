# multiagent-setup の回帰テスト

テストケースは [`evals.json`](evals.json)。実行・採点・集計の共通手順は `docs/skill-development.md`「回帰テストを実行する」に従う。

スキル作成手順の「書く前と書いた後にスキルの有無で比べる」段は、eval 1・8・9 で確かめる。
eval 1 は、依頼に書いた期待する振る舞いで比べてからスキルを作る流れを確かめる。
スキル無しで 3 回とも起きて作るかを確かめる分岐に入ることもあり、どちらも取り決めどおりなので両方を合格にする。
eval 8 は、スキルが無くても期待する振る舞いが起きる依頼で、スキルを書かずに止まる分岐を確かめる。
eval 9 は、依頼に期待する振る舞いが無いときに、自分で決めずに候補を示して止まる分岐を確かめる。
eval 9 の「食い違う判断をしていない」は without_skill も満たすので、Delta には寄与しない。止まると言いながら比べる実行に進む後退を検出するために置く。
4 のやり直しが 3 回に達して止まる分岐は、どの依頼でその状態になるかを決められないので、eval で確かめていない。
eval 1 の prompt は、比べる実行のコピーの作り方と片付けを利用者が決めた形で渡す。決めていないと、非対話の実行はコピーの案を示して止まり、作成の流れまで進まない。
コピーの案を示して止まる分岐は、eval で確かめていない。
