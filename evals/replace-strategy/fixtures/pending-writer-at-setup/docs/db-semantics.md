# DB 意味論（現行 DB → 新 DB）

- 最終更新: 2026-07-20T09:00:00+09:00
- 現行 DB: CurrentSQL 9（現行テスト環境で実測）
- 新 DB: NewSQL 4（採用は決定済み。実測は未着手）

## 型マッピング

| 現行の型 | 新側の型 | 備考 |
|---|---|---|
| VARCHAR2(n) | varchar(n) | 実測済み。長さの単位は文字数で一致 |
| NUMBER(p,s) | numeric(p,s) | 実測済み |
| DATE | timestamp | 実測済み。現行の DATE は時刻を持つ |

## 移植時の点検項目

### NULL の並び順

- 現行 DB: 昇順で NULL が末尾（実測）
- 新 DB: 未実測

### 暗黙の型変換と、変換に失敗したときの値

- 現行 DB: 文字列と数値の比較で数値へ寄せる。変換できない入力はエラー（実測）
- 新 DB: 同じくエラー（一次ドキュメントで確認）

### 照合順序（collation）

- 現行 DB: 大小を区別し、全角半角は別文字として扱う（実測）
- 新 DB: 未実測

### 連結における NULL の扱い

- 現行 DB: NULL を空文字として連結する（実測）
- 新 DB: NULL を伝播して結果が NULL になる（一次ドキュメントで確認）

### 数値・日付の書式のロケール依存

- 現行 DB: セッションの地域設定に依存する（実測）
- 新 DB: 依存しない（一次ドキュメントで確認）
