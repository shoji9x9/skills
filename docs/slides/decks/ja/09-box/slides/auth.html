認証

設定した環境変数によって、2 つの方式のどちらかを使う。

方式特徴
Dev TokenBox Developer Console で発行する、60 分有効なトークン。すぐ使えて管理者の承認は要らないが、期限が切れるたびに発行し直す
OAuth refreshrefresh token から、access token をそのつど取得する。長く使える。refresh token は使うたびに変わるので、スクリプトが保存し直す。最初の 1 回だけ、人が認可の手順を行う

トークン・client secret・refresh token は、環境変数かリポジトリの外のファイルで管理する。エージェントは値をログや出力に書かず、利用者が示した値も繰り返さない。
