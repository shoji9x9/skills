呼び出し方

初回は setup で導入し、以降は update で図を作り直す。

  • setup: 図の置き場所・アイコン・図を持つ環境を、利用者に確かめながら決め、最初の図を作る
  • update: 情報源の変化を spec に反映し、SVG を作り直す
  • --env を省くと、図を持つ環境すべてを作り直す。差分が出るのは変わった図だけ
  • --from で、情報源にする IaC のパスを指す

呼び出し方

aws-architecture-diagram
setup --from <IaC のパス>
aws-architecture-diagram
update --env <環境名>

「CDK から構成図を描いて」「構成図を更新して」のように頼んでもよい
