issue-batch

複数の Issue を、Issue ごとの worktree・ブランチ・PR で、merge まで順に処理する。

  • setup で、無人で実行する方針と merge の方式を決める
  • prepare で、判断が要るものを先に決めて Issue に記録する
  • run で、依存先から順に、実装・レビュー・PR の収束・merge・片付けまで進める
  • PR の merge・Issue の close・deployment の成功・ブランチの片付けを確かめてから、完了にする

呼び出し方

issue-batch setup
issue-batch prepare <Issue>...
issue-batch run <Issue>...

中で issue-start・git-worktree・kaizen・pr-finalize-loop を使う
