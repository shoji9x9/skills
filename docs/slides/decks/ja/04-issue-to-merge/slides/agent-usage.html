agent-usage

エージェントの費用と稼働状況（動いていた時間・止まっていた時間）を記録して集計する。

  • commit の前の Hook が、ブランチごとに記録するかを確かめる
  • モデル別・日別のトークン数と費用を記録する
  • 1 回の指示で動き続けた時間と、止まっていた時間（人の確認中・CI 待ち・レビュー待ち・未活用）を記録する
  • 要約は HTML、明細は CSV に集計する

呼び出し方

agent-usage setup
agent-usage report

対象は Claude Code と Codex。記録は .agent-usage/ に人別に残る
