規則の例

行為者を主語にする

前: 古い宣言が残ると、範囲を狭めても静かに通る。

後: 古い宣言が残っていると、範囲を狭めてもチェックはエラーを出さない。

名詞を「の」で連ねない

前: 保守性担保機能の形骸化の防止

後: 保守性を守る仕組みが使われなくなるのを防ぐ

否定と対比で演出しない

前: 終了コードではなく、狙った assertion が落ちたことで判定する——終了コードは起動失敗でも非 0 になる。

後: 狙った assertion が落ちたことで判定する。終了コードは起動に失敗したときも 0 以外になるので、判定に使えない。

総称には例を添える

前: 型の検査を外す書き方を禁じる。

後: 型の検査を外す書き方（!・as・any・@ts-ignore）を禁じる。

規則は全部で 10 ある。ほかに、比喩の動詞を使わない、文末をコロンで続けない、状態を書かない、などがある。
