呼び出し方

確かめる環境と、どの変更を確かめるか（スコープ）を指定する。

  • uncommitted: commit していない変更（デフォルト）
  • branch: ベースブランチからの変更
  • custom: 確かめるページと観点を利用者が指定する
  • 初回は setup で、環境・起動の方法・認証・禁止する操作を設定ファイルに記録する

呼び出し方

browser-test setup
browser-test --env <環境名>
--scope <uncommitted|branch|custom>

引数を省くと、環境とスコープを利用者に確かめる。「画面で確認して」のように頼んでもよい
