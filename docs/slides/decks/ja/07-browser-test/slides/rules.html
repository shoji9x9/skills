安全のための決まり

実行してよい操作は、環境ごとの設定と人の承認で決める。

操作扱い
副作用の無い操作承認なしで実行する（ページの移動・検索の入力・タブの切り替え・フィルタの選択など）
副作用を伴う操作「保存」「削除」「送信」など、書き込み・課金・生成・通知を伴う操作は、内容と影響を伝えて承認を得てから実行する
禁止する操作環境ごとの forbidden_actions に当たる操作は実行せず、利用者に実施を頼む
設定の無い環境読み取り専用として扱う

ローカルの環境でも、共有の DB や外部の API を使っているかもしれない。分かれていると確かめられない限り、共有の環境に影響する前提で承認を求める。
