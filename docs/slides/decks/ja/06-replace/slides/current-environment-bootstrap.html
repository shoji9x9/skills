current-environment-bootstrap

受け取った資産だけから、比べる基準になる現行のテスト環境を作り直す。

  • 資産を棚卸しし、受け取った・導き出せる・足りない、に分ける
  • 型や列の名前から、値を推測して確定しない
  • 足りない情報は、現行アプリの担当者や業務の専門家への質問票にする
  • 起動・認証・主要な画面に着けることを測り、空の環境から作り直せることを確かめる

呼び出し方

current-environment-bootstrap
current-environment-bootstrap --resume

現行環境を受け取った資産から作り直すときだけ、replace-strategy の setup から呼ばれる
