replace-strategy

現行を測って戦略を決め、機能に分けて姉妹スキルに振り分ける。自分では実装しない。

  • 現行アプリを測って戦略を決める。測れなければ止まる
  • 仕様は、実行ログ → ソースコード → API → UI の順に、費用の低い方法から確かめる
  • 機能に分け、依存の順に Issue を起票する（起票は issue-create に任せる）
  • status で、Issue と成果物から今の状況と未検証の領域を示す

呼び出し方

replace-strategy setup
replace-strategy issues
replace-strategy status
