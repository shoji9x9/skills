Sharing across agents

Claude Code, Codex, and GitHub Copilot read the same skills, rules, and docs.

TargetHow it is shared
DocsAGENTS.md holds the shared content, and CLAUDE.md only imports it
SkillsThe files live in .agents/skills/, and .claude/skills/ links to them
RulesThe files live in .agents/rules/, and .claude/rules/ and .github/instructions/ link to them
