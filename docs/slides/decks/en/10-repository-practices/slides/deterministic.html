Not relying on probabilistic behavior

Agent behavior is probabilistic. What must hold is enforced by the deterministic behavior of tools, not by instructions alone.

What must holdDeterministic mechanism
Repository conventionspre-commit and CI checks verify them
Banned wordstextlint finds them in docs, and a Stop Hook finds them in replies to people
Learnings from failuresA Hook before commit prompts the agent to extract learnings
Current vs. new app differences (Chapter 6)A tool detects differences, and the model only classifies them
Architecture diagrams (Chapter 8)The agent writes a spec, and an engine draws the diagram
