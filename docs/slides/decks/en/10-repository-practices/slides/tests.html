Quality: tests

Passing tests are not enough. The repository also checks that tests can catch errors.

MechanismWhat it checks
Regression evalsAfter a skill changes, the agent still behaves as expected in the scenarios set for each skill
Mutation testingWhen the code is deliberately broken, the intended test fails
Coverage thresholdsFor each file, the lines and branches the tests run exceed the threshold

Expected values in tests come from the spec, not from the code's output.
