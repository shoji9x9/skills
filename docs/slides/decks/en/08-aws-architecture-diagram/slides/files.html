What gets copied and what does not

The skill copies as little as possible, so skill updates do not overwrite the user's files.

Copied once into the project

The spec, environment definitions, icon mapping, and generic icons. After copying, the user edits them. Updates do not overwrite them.

Not copied, run from the skill

The rendering engine, the scripts that create SVG and PNG, and icon fetching. gh skill update keeps them current.
