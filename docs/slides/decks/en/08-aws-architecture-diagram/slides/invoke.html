How to invoke

You run setup the first time, then update to regenerate diagrams.

  • setup: decides the diagram location, icons, and environments with the user, and draws the first diagram
  • update: applies source changes to the spec and regenerates the SVG
  • Without --env, it regenerates every environment. Only changed diagrams show a diff
  • --from points to the IaC path to use as the source

How to invoke

aws-architecture-diagram
setup --from <IaC path>
aws-architecture-diagram
update --env <env>

You can also ask "Draw an architecture diagram from CDK" or "Update the architecture diagram"
