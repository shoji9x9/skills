How it works

The agent writes the spec, and the bundled engine creates the SVG.

Source

IaC or a description

CDK, Terraform, CloudFormation, existing diagrams

spec

Nodes, edges, groups

The agent reads the source and writes it by the diagram rules

SVG

One diagram per environment

The bundled engine generates it from the spec

Review

Check it visually as PNG

If the layout is off, fix spec coordinates and regenerate

The skill does not parse IaC automatically, so it works the same with CDK or Terraform. Image-reading tools cannot render SVG, so the skill converts to PNG first.
