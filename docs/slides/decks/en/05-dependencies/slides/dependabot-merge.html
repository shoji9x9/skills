dependabot-merge

Checks the impact of a Dependabot PR, records the decision, then merges.

  • Confirms that the required CI checks pass
  • Reads the changelog and release notes for impact on the code that uses the package
  • Comments the decision to merge (or not) and the reasons on the PR
  • With --all, processes every open Dependabot PR in turn

How to invoke

dependabot-merge <PR>
dependabot-merge --all
