dependabot-alert-issue

Sorts and groups vulnerability alerts, then creates issues to fix them.

  • Applies ignore and dismiss from the config, and skips alerts that already have an issue or PR
  • Groups the rest by whether work can start now
  • Runs the drafts and dismiss candidates after your approval
  • Also accepts external audit results (such as pnpm audit) besides Dependabot alerts

How to invoke

dependabot-alert-issue
