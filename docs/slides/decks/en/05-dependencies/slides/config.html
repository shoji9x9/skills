Configuration

You write each repository's policy in a config file, not in arguments.

SkillKeyWhat to write
dependabot-mergemerge_methodMerge method (squash, merge, rebase)
dependabot-alert-issueminimum_release_age_daysMinimum days from the fixed version's release before work starts
dependabot-alert-issueignoreConditions for alerts to ignore
dependabot-alert-issuedismissAlerts to dismiss with a reason (by advisory or package)
