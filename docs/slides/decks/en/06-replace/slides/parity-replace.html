parity-replace

Implements the new app against parity-suite's logical names. A thin layer that handles only what is specific to replacement.

  • Splits a feature into phases by page
  • Maps new app elements only where they differ from the logical names
  • A reviewer separate from the implementer reviews the uncommitted changes
  • Done when the suite passes on the new app, the verify commands pass, and the acceptance criteria are checked

How to invoke

parity-replace --feature <slug>

issue-start handles the branch, commits, and PR
