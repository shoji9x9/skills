spec-parity

Replaces parity-suite and parity-diff for features with screens when style_policy is free.

ModeWhat it does
suiteBuilds an e2e suite (actions, states, assertions per role, API) against the current app, makes it pass, and injects faults to check its strength. Records the baseline of runtime errors and the screen widths where the current app does not overflow
verifyChecks only the new app. Tools judge the suite, horizontal overflow and runtime errors; approval records judge the design review and human check
  • Never compares screens or asks the model "Is this OK?" for pass/fail
  • Sends must-fix items to parity-replace. Keeps approvals append-only and checks none shrank before calling it done

How to invoke

spec-parity suite --feature <slug>
spec-parity verify --feature <slug>

Handles one feature per run. Does not fix the new app
