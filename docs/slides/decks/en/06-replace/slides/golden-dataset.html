golden-dataset

Builds an idempotent, deterministic loader that puts the same data into both apps.

  • Builds a loader, not the data; every run gives the same state
  • Creates data from scratch without reading production
  • Phase A designs the logical data and loads it into the current app to check it
  • Phase B converts it to the new app's schema, loads it, and checks it matches the current app
  • The dataset version reveals outdated baselines

How to invoke

golden-dataset --phase a
golden-dataset --phase b --feature <slug>
