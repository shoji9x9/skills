parity-diff

Deterministic tools detect differences; the model only classifies them.

DetectionWhat it compares
PixelsScreenshot differences. Only this catches visual differences in unnamed elements
StylesComputed styles, pseudo-elements, and positions of elements with logical names
StructureRows, columns, value order, and structure of tables and forms (aria snapshots)
  • Asks the model only "Does this difference matter?" and sorts into must-fix, acceptable, or environment noise
  • Sends must-fix differences back to parity-replace; done when no unexplained differences remain

How to invoke

parity-diff --feature <slug>

This skill does not fix differences
