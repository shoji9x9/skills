parity-component

When you build shared UI components before screens, captures a visual baseline from the current app, implements, and compares.

  • Captures element screenshots and per-state styles for each component × page
  • Compares the same component across pages. Looks that vary by page (width, color) become arguments; looks that never vary are fixed inside
  • Places the built component in a catalog, captures it the same way, and compares until zero differences
  • Handles one component per run

How to invoke

parity-component capture
parity-component build

Skip it if you do not build components first. parity-replace then builds them per feature
