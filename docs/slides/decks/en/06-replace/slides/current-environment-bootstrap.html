current-environment-bootstrap

Rebuilds the current app's test environment, the baseline for comparison, from received assets only.

  • Inventories the assets as received, derivable, or missing
  • Does not guess and fix values from type or column names
  • Turns missing information into questions for the current app's owners and domain experts
  • Measures startup, login, and reaching the main screens, and confirms a rebuild from an empty environment

How to invoke

current-environment-bootstrap
current-environment-bootstrap --resume

replace-strategy setup calls it only when rebuilding the current environment from received assets
