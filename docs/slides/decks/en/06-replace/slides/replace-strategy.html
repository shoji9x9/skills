replace-strategy

Measures the current app, decides the strategy, and splits the work into features for the sister skills. It does not implement.

  • Measures the current app to decide the strategy; stops if it cannot measure
  • Checks behavior in order of cost: execution logs → source code → API → UI
  • Splits into features and files issues in dependency order (issue-create files them)
  • status shows progress and unverified areas from issues and outputs

How to invoke

replace-strategy setup
replace-strategy issues
replace-strategy status
