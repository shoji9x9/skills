Flow

1

Choose environment and scope

If the environment needs auth, the user logs in

2

Check the server is running

If not, show the start command and ask the user

3

Find affected pages

From router definitions and pages that call the API

4

Check each page

Display, console error and warn, API responses

5

Isolate issues in another environment

See if they reproduce without the change

6

Report

A check × page × result table, and isolation results
