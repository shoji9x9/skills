How to invoke

You specify the environment and which changes to check (the scope).

  • uncommitted: uncommitted changes (default)
  • branch: changes from the base branch
  • custom: the user names the pages and checks
  • The first time, setup records environments, start method, auth, and forbidden operations in the config file

How to invoke

browser-test setup
browser-test --env <env>
--scope <uncommitted|branch|custom>

Without arguments, the skill asks the user for the environment and scope. You can also ask "Check it in the browser"
