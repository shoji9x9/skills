Configuration

For each environment, you write the URL, how to start it, and forbidden operations under environments in the config file.

KeyWhat to write
name, defaultThe environment name, and whether it is used when no argument is given
url, check_urlsThe URL to open, and the URL that checks whether the server is running
pre_commands, startCommands to run before starting (such as build) and the start command. The skill does not run them. It shows them to the user
authWhether authentication is needed (none or user)
forbidden_actionsUI operations the skill does not run in that environment
