How to invoke

Ask with requests like "Initialize the project" or "Add a rule". Each target has a fixed set of outputs.

TargetWhat it creates
SkillsPuts the source in .agents/skills/ and links to it from .claude/skills/
RulesPuts the source in .agents/rules/ and links to it from .claude/rules/ and .github/instructions/
HooksPuts shared scripts in .agents/hooks/scripts/ and calls them from each agent's configuration file
DocsWrites AGENTS.md in a fixed structure and adds sections on choosing the type and on response policy. CLAUDE.md and .github/copilot-instructions.md get only the differences
AllInitializes the project. Creates all four of the above at once
