Authentication

The environment variables you set decide which of two methods it uses.

MethodCharacteristics
Dev TokenIssued in the Box Developer Console and valid for 60 minutes. Works right away with no admin approval, but you issue a new one each time it expires
OAuth refreshGets an access token from the refresh token each time. Lasts long. The refresh token changes on every use, so the script saves the new one. A person authorizes once, the first time

Keep the token, client secret, and refresh token in environment variables or in a file outside the repository. The agent does not write the values to logs or output, and does not repeat values the user shows it.
