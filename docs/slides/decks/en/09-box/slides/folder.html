Target folder

The root_folder_id setting decides which folder it works on.

  • For a folder the whole team shares, put it in the repository config
  • For your own folder, put it in the .local config
  • If neither has it, the target is the Box root
  • The folder ID is at the end of the URL when you open the folder in Box

Example config

// .config/skills/
// shoji9x9/box.jsonc
{ "root_folder_id":
"123456789" }
