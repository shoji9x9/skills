Extend with project rules

The skill's rules are a minimal set. A project adds rules by writing 3 keys in a config file.

KeyValueWhat the agent does
style_docsDocuments with the writing rulesFollows them on top of the rules. On conflict, these documents win
word_listWords to avoid and their replacementsReplaces listed words with their replacements
lint_commandCommand that checks textRuns it on edited files and fixes the findings
