kaizen

Extracts learnings from session failures and applies them to skills, rules and Hooks.

  • When the pre-commit check finds candidate learnings, it stops the commit and asks for extraction
  • Learnings stay in .kaizen/, and every agent reads them
  • apply prefers deterministic mechanisms such as linters and Hooks
  • Learnings that go stale without being applied are dropped automatically

How to invoke

/kaizen
/kaizen apply

Run /kaizen setup once to install the Hook
