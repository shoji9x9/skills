issue-batch

Takes several issues to merge in order, each with its own worktree, branch and PR.

  • setup sets the unattended policy and the merge method
  • prepare settles decisions early and records them on the issues
  • run goes dependencies first: implement, review, settle the PR, merge, clean up
  • Marks an issue done after confirming the PR merge, issue close, successful deployment and branch cleanup

How to invoke

issue-batch setup
issue-batch prepare <Issue>...
issue-batch run <Issue>...

Uses issue-start, git-worktree, kaizen and pr-finalize-loop inside
