pr-review-handle

Takes each review finding through a fixed sequence to the end.

Read

Assess

Fix (only if needed)

Reply

Resolve

  • Handles findings from every reviewer, including Copilot
  • For findings it does not fix, replies with the reason before resolving
  • With --push, it also commits, pushes and requests a re-review

How to invoke

pr-review-handle <PR> --push
