git-worktree

Creating a worktree alone does not isolate work. Isolation holds once the session moves into it.

  • Prepares a worktree on the given branch and moves the session there
  • Carries over files listed in .gitignore (such as .env)
  • Excludes the worktree from check tools
  • Confirms it is clean before removing it

How to invoke

git-worktree enter <branch>

It does not create branches. The caller, such as issue-start, creates and passes one
