issue-start

Creates a branch linked to the issue. A mode sets how far the agent goes.

  • Creates the branch with gh issue develop and links it to the issue
  • Rechecks the scope written in the issue against the current code
  • Before push, matches each acceptance criterion with evidence

How to invoke

issue-start <number> --pr

ModeGoes up to
NoneImplementation
--planThe plan
--commitCommit
--prOpening the PR
--acceptanceOnly checks acceptance criteria
