agent-usage

Records and totals agent cost and activity (time running and time stopped).

  • A pre-commit Hook asks whether to record each branch
  • Records tokens and cost per model and per day
  • Records how long one instruction kept it running, and stopped time (human review, CI, code review, idle)
  • Totals a summary in HTML and details in CSV
