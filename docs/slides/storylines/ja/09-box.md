# 9. box

伝えること: Box のファイルを API で扱う。

## スライド

1. 困りごと。エージェントから Box のファイルを扱うために、MCP や SDK を入れたくない。トークンや client secret を、ログ・出力・リポジトリに残さずに使いたい。
   根拠: `skills/box/SKILL.md` の冒頭と「認証」
2. 呼び出し方。「Box のフォルダを一覧して」「Box にアップロードして」のように頼む。`curl` と `jq` だけで動く。
   根拠: `skills/box/SKILL.md` の `description` と冒頭
3. 認証。すぐ使える Dev Token と、長く使える OAuth refresh の 2 つの方式から選ぶ。refresh token は使うたびに変わるので、スクリプトが保存する。秘密の情報を出力に書かない。
   根拠: `skills/box/SKILL.md`「認証」
4. 対象のフォルダ。設定の `root_folder_id` で、操作の対象のフォルダを決める。全員で共有するならリポジトリの設定に、自分だけなら `.local` の設定に書く。
   根拠: `skills/box/SKILL.md`「対象フォルダ」
5. できること。フォルダの一覧、メタデータの取得、ダウンロード、検索、アップロード、新しいバージョンのアップロード。
   根拠: `skills/box/SKILL.md`「レシピ」
6. 注意。書き込んだ後は読み直して結果を確かめる。rate limit では待ち時間を延ばしながら再試行する。共有リンクだけの権限なら `BoxApi` ヘッダを付ける。単独で使うので、つながるスキルのスライドは置かない。
   根拠: `skills/box/SKILL.md`「注意」
