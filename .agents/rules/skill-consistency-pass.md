# 配布スキル変更時の整合パス

配布スキルを変更したら、正本である `docs/skill-development.md` の「push 前の整合パス」を実行する。
特に、新設・変更した契約は義務づけた記述から消費側を逆引きし、記録を要求するなら成果物テンプレートに対応する節・列があることまで確認する。

**完了報告には整合パスの実行結果を添える**——grep した語（足した語ではなく**既存要素名**）と、語ごとのヒット件数・確認したファイルを書く。
整合パスは強制点を持たない散文なので、通過を示さない完了報告は「実行した」と「飛ばした」が同じ見え方になる（飛ばしてレビュー 1 往復ぶん手戻りした記録が 4 回ある）。
