# 配布スキル変更時の整合パス

配布スキルを変えたら、`docs/skill-development.md` の「push 前の整合パス」を実行する。
新しく足した取り決めや変えた取り決めは、それを義務づけた記述から、従う側の文書を探して確かめる。
記録を求める取り決めなら、成果物のテンプレートに対応する節や列があることまで確かめる。

完了報告には整合パスの実行結果を添える。grep した語（足した語ではなく、既にある要素の名前）、語ごとのヒット件数、確かめたファイルを書く。
整合パスはチェックするツールを持たない手順なので、結果が無い完了報告では、実行したのか飛ばしたのかを読み手が区別できない。
